# Project_JUnit-

1. Create a class requiring all the tests below. Your mark will not only be based on your ability to test the class but also on your knowledge and understanding of what tests are appropriate as well as the complexity of your tested class.
2. Test Cases: - Write JUnit test cases to thoroughly test the class that you’ve created to be tested methods. - Ensure to cover normal scenarios as well as edge cases for each method.
3. Mockito Usage: - Identify scenarios where mocking is necessary and use Mockito to create mocks. - For example, consider mocking external dependencies or objects with complex behaviors that are not directly related to the functionality being tested.
4. Exception Handling: - Write tests to check if the `IllegalArgumentException` is correctly thrown when attempting to send illegal input in one of the methods.
5. Test Setup and Tear Down: - Use JUnit annotations such as `@Before` and `@After` to set up and tear down necessary resources or configurations before and after test execution.
